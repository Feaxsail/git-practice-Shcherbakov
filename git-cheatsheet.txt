===========================================
ШПАРГАЛКА ПО ОСНОВНЫМ КОМАНДАМ GIT
===========================================

ОСНОВНЫЕ КОМАНДЫ:
------------------
1. Настройка пользователя:
   git config --global user.name "ВашеИмя"
   git config --global user.email "ваша@почта.ru"

2. Инициализация репозитория:
   git init -b main

3. Проверка статуса:
   git status

4. Добавление файлов в индекс:
   git add <файл>      # конкретный файл
   git add .           # все файлы

5. Создание коммита:
   git commit -m "Сообщение коммита"

6. Просмотр истории:
   git log             # подробная история
   git log --oneline   # компактный формат
   git show <хеш>      # детали конкретного коммита

РАБОТА С ВЕТКАМИ:
------------------
1. Создание и переключение:
   git checkout -b <имя_ветки>    # старый способ
   git switch -c <имя_ветки>      # новый способ (Git 2.23+)

2. Переключение между ветками:
   git checkout <ветка>           # старый способ
   git switch <ветка>             # новый способ
   git switch -                   # на предыдущую ветку

3. Просмотр веток:
   git branch                     # локальные ветки
   git branch -a                  # все ветки (локальные + удаленные)

4. Удаление веток:
   git branch -d <ветка>          # безопасное удаление
   git branch -D <ветка>          # принудительное удаление

РАБОТА С УДАЛЕННЫМИ РЕПОЗИТОРИЯМИ:
-----------------------------------
1. Подключение удаленного репозитория:
   git remote add origin <URL>

2. Проверка подключенных репозиториев:
   git remote -v

3. Отправка изменений:
   git push -u origin main        # первая отправка
   git push                        # последующие отправки

4. Отправка новой ветки:
   git push --set-upstream origin <имя_ветки>

5. Загрузка изменений:
   git pull                        # загрузить и объединить
   git fetch --prune              # только загрузить, удалить несуществующие ветки

РАБОТА С GITFLIC:
-----------------
1. Создание Pull Request:
   - Перейти во вкладку "Запросы на слияние"
   - Нажать "Создать запрос на слияние"
   - Выбрать ветки (источник и цель)
   - Добавить описание и подтвердить

2. Настройки слияния на GitFlic:
   - "Удалить исходную ветку после слияния"
   - "Выполнить слияние одним коммитом (Squash)"

ИГНОРИРОВАНИЕ ФАЙЛОВ:
---------------------
1. Исключение файлов из отслеживания:
   - Создать файл .gitignore
   - Добавить имена файлов/папок
   - Закоммитить изменения

ПРИМЕРЫ ИЗ ЛАБОРАТОРНОЙ РАБОТЫ:
------------------------------
1. Проблема: "fatal: The current branch feature has no upstream branch"
   Решение: git push --set-upstream origin feature

2. Проблема: "Your branch is behind 'origin/main' by X commits"
   Решение: git pull

3. Проблема: Не видно папок bin и obj в VS Code
   Решение: Они игнорируются через .gitignore и скрыты в настройках VS Code

4. Команды для работы с .NET проектом:
   dotnet new console -o Program --use-program-main
